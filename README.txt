錬金堂 — 月影と硝子の調合室
==========================

錬金術師ショップ経営ゲーム（縦切りプロトタイプ）

■ 遊びかた
  index.html をブラウザで開くだけです。
  Chrome / Edge / Firefox / Safari の比較的新しいバージョンで動作します。
  サーバ不要、インターネット接続不要、インストール不要。

■ ゲームの流れ
  朝：冒険者を雇い／装備・魔法・特性・戦略を整え、採取地に派遣
  昼：店頭の棚にアイテムを並べ、調合（クラフト）を行う。客が来訪し購入
  夕：派遣の結果と本日の売上をご報告。戦闘ログも閲覧可
  夜：金貨を投資して新レシピを研究、必要なら記録をエクスポート、翌日へ

■ 冒険者ランクと特性
  F:0 / E〜C:1 / B〜A:2 / S:3  の特性スロット数。
  ランクは雇用時に固定、レベルアップでHP/攻/守/運が成長します。
  魔法スロット数も雇用時から変動しません。

■ 職業
  戦士・騎士・魔法使い・盗賊・薬師・狩人・木こり・採掘師（8職業）

■ 魔法の属性相性
  火 → 風 強 / 水 弱
  水 → 火 強 / 風 弱
  風 → 水 強 / 火 弱
  光 ↔ 闇 互いに強い

■ セーブデータ
  夜パネルやタイトル画面の「セーブコードを表示」を押すと、
  改竄防止チェックサム付きの記録コードが表示されます。
  テキストとしてコピー保管し、次回はタイトル画面から貼り付けて読込。

■ フォントについて
  Oradano明朝GSRRフォント（内田明氏 制作）を同梱しています。
  再配布自由・商用可。詳細は assets/fonts/OradanoGSRR-README.txt を参照。

■ 配布物
  index.html       : エントリ
  css/             : スタイル
  js/              : 全ロジック・データ・UI
  assets/fonts/    : フォントとREADME（クレジット）
  README.txt       : 本ファイル

■ 開発メモ
  ・素のESM。ビルドツール・npm 不要
  ・全データは JSの export const なので file:// 直開きでも動作
  ・効果音／BGMは未実装（後付け用のフック余地あり）
