# ミステリアス・スペシメン：廃都の調合師

廃都を探索し、敵から得た「生体標本」や「鉱物」を釜で煮込み、自分にセットする「スキルフラスコ」を作り出す **ハクスラ＆調合RPG** の縦スライス版。

## 起動方法

### 配布パッケージから（一番簡単）

`game1-slice.zip` を解凍して、中の `dist/index.html` を最新のブラウザで開くだけです（ローカルファイル `file://` で動きます）。

ブラウザのセキュリティ設定で `file://` でモジュールがブロックされる場合は、簡易サーバを立ててください：

```sh
cd dist
python3 -m http.server 8080
# → http://localhost:8080
```

### ソースから

```sh
npm install
npm run dev          # 開発サーバ：http://localhost:5173
npm run build        # 本番ビルド：dist/ に出力
npm run preview      # ビルド済みをプレビュー
```

## 遊び方

### コアループ

```
拠点で調合 → スキル装備 → 廃都へ → 戦闘で素材＆gold獲得
        ↑                                    ↓
        └────────────── 拠点に戻る ─────────────┘
```

1. **拠点（研究室）** で `🜲 調合する` を選び、素材2 ＋ 属性1 を選んで調合する
2. 完成した **スキルフラスコ** を `⚔ ロードアウト` で5枠に装備する
3. `🛒 ショップ` で武器・防具・装飾を購入して強化する
4. `🗡 廃都へ` で探索開始。ターン制コマンド戦闘で敵を倒す
5. 素材と gold を持ち帰り、再び調合する

### 調合システム

- **2素材 + 1属性（火・水・風・光・闇）** で1つのスキルを生成
- **手書きレシピ表**にヒットすれば「スキル発見」
- **外れた組み合わせは「失敗」として：**
  - 70% で換金品を獲得（自動で gold に変換）
  - 25% で永久ステータス上昇（ATK / DEF / MaxHP）
  - 5% で **突然変異スキル**（通常レシピでは作れない強力なスキル）

→ どんな調合をしても無駄にはならない。気軽に実験を。

### 装備（拠点ショップで購入）

- **武器**：ATK増加。属性特化武器は対応スキルのダメージを増やす
- **防具**：DEF・最大HP増加
- **装飾**：属性ボーナス + サブステ

`👑 ボス撃破後` に解禁される高性能装備もある。

### セーブシステム

- **3スロットセーブ**（タイトル画面・拠点のセーブメニューから）
- **インポート／エクスポート**：エクスポートで Base64 文字列を出力し、コピーして他の環境にペースト
- **改竄防止（HMAC-SHA256）**：localStorage を直接編集しても、ロード時に弾かれます
- 拠点に戻ったとき・調合後・購入後・戦闘勝利後に **自動セーブ**

### 戦闘の小ネタ

- 属性相性：火→風、風→水、水→火 で +50%。光⇄闇は互いに +50%。同属性は -50%。
- 状態異常：毒・呪い・火傷は毎ターン継続ダメージ。気絶・守護・加速もある
- スキルにはクールダウンあり（CD中は通常攻撃に置換される）
- ボスからは逃げられない

## 技術スタック

- TypeScript（strict）
- Vite 5
- DOM + CSS（Canvas/WebGL不使用）
- Web Crypto API（HMAC-SHA256）
- 画像なしのテキストUI（絵文字・ASCIIアート）

## 改竄防止について

ブラウザゲームの性質上、鍵がクライアントに存在するため **完全な改竄防御は不可能** です。本作の改竄防止は次の目的のためのものです：

- localStorage を手動編集する casual な書き換えを弾く
- エクスポート文字列の途中改ざんを検出する
- 「正しいセーブ」と「壊れたセーブ」を区別する

ビルド時に `SAVE_KEY` 環境変数を設定すると鍵を差し替えられます：

```sh
SAVE_KEY="your-secret" npm run build
```
